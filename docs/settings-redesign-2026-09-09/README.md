推荐的信息归属不随选择哪张布局而改变：

| 入口 | 管理什么 | 保存与生效 |
| --- | --- | --- |
| 设置 → Agent | 连接列表、启动命令/参数、进程目录、环境变量、默认 Agent | 应用配置草稿，统一保存；当前实现会重载 controller |
| 设置 → 工具与目录 | MCP 连接、全局额外目录 | 应用配置；全局目录会影响后续会话，不是某个项目专属目录 |
| 设置 → 权限 | 客户端文件读写、越界读取、终端能力、信任规则、自动审查来源 | 应用配置；与输入区当前执行策略分开解释 |
| 设置 → AI 助手 | 标题/总结助手、模型及可选增强 | 应用配置；默认关闭，仅启用时展开依赖控件 |
| 设置 → 本地存储 | 恢复数据容量与保留策略；配置文件来源 | 应用配置；侧栏索引与恢复 payload 不混为同一种数据 |
| Agent 菜单 | 当前 Agent 切换、认证、退出、重连；管理 Agent 的深链 | 当前连接；切换不等于持久化修改默认 Agent |
| 当前会话参数 | Agent 暴露的模型、推理强度、模式与其它参数 | 选择后即时调用 Agent，不写应用配置；输入区保留常用快捷项 |
| 会话菜单 | 重命名、置顶、归档、复制、继续、关闭/删除等 | 明确目标会话；归档、释放资源、删除远端历史保持独立 |
| 工作区菜单 | 在此新建/恢复、Finder、worktree、侧栏组织 | 以目标目录/工作区为上下文；不新增工作区级 settings 文件 |
| 活动与诊断 | 事件、权限历史、运行配置和能力 | 只读状态与排错；可从上下文深链到同一视图 |

## 本轮实施边界

两份盘点文档的“建议”包含长线候选。下面的范围决策优先于其中尚未选择的扩展建议：

1. 重排现有字段和入口，保留完整配置兼容与原子保存；不为表单重排改造 Rust 运行时或新增第二执行链。
2. Agent/MCP 编辑合入明确的应用草稿，消除两个同名 Save 的歧义。未修改时不执行保存；离开未保存草稿需能继续编辑或明确放弃；保存失败保留输入并定位错误。
3. 保存通常会立即重建 controller。活动操作期间禁止写入；若写入等待期间才开始会话操作，则已提交配置等待所有 controller 空闲后再应用。该竞态路径已有独立集成测试；不承诺当前会话无感保留。
4. Reviewer 的旧开关表示是否使用显式 reviewer 配方，关闭仍可能在用户选择 Auto Review 时使用当前 Agent。新表单应直接表达审查来源和当前执行策略，不把关闭该开关伪装成禁用自动审查。
5. 已有模板可以展示只读的来源、继承与最终配置摘要，并保持保存透传。本轮不承诺完整模板 CRUD、版本迁移编辑器、逐项目覆盖系统或任意新建会话高级覆盖。
6. 不新增存储清理中心、功能使用遥测或连接安装商店；不在设置页宣传不可执行的远程 ACP/MCP-over-ACP。
7. Agent process cwd、session workspace cwd、additional directories 使用不同标签；默认 Agent 与当前 Agent 分开标识。
8. 现有未知字段、旧 transport、secret refs、稳定身份和模板关联均须无损保留；新表单不能把高级字段隐藏后丢弃。

## 实施后应提供的对照证据

| 要求 | 验收证据 |
| --- | --- |
| 常用设置可发现 | 默认进入 Agent；五组导航稳定；从 Agent 菜单直接进入连接管理 |
| 表单不会丢草稿 | 切分类/连接保留编辑；取消、关闭、保存失败的行为可复验 |
| 保存影响诚实 | 无改动不重载；活动状态限制、成功重载和恢复提示与真实链路一致 |
| 所有配置保留 | 含模板、未知字段、旧 transport、secret refs 和身份字段的 round trip 测试 |
| 当前会话参数独立 | 不出现应用 Save；即时更新有等待/失败反馈；快捷项共用状态 |
| 会话操作不丢失 | 关闭、删除从参数表单迁移到能力驱动菜单；归档语义与撤销保留 |
| 布局与选图对应 | 相同视口和状态的设计图/实际截图并列；逐项标注差异及修复 |
| 原有保护不退化 | 必要组件/配置/app 集成测试、分析、真实 macOS 操作；预算与长列表渲染检查 |
