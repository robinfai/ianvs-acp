# ACP runtime coverage — superseded

Updated: 2026-09-09

Current application capabilities are maintained in
[Product capabilities](product_capabilities.md). Runtime ownership, transport,
FFI boundaries, and recovery behavior are maintained in
[Runtime architecture](runtime_architecture.md).

The separate Protocol Coverage screen has been retired. Open **Activity &
Diagnostics → Runtime → Capability details** to inspect the capabilities
negotiated for the current connection.

This path remains available for existing links. Its previous implementation
summary is retained in Git history; it is no longer a separate capability list.
