# 全项目安全复审后续整改设计

日期：2026-07-11

## 背景与目标

在提交 4b37f58c94115cafd11885f18cd1e0523951b345 上完成的全项目复审覆盖了 115 个主工作清单文件和 38 个补充安全文件，最终保留 11 个中等、27 个低严重度问题。整改目标是关闭全部可达路径，并在修复后按相同范围重新评审，直到没有未解决问题。

## 方案比较

方案一是逐项增加局部判断，改动小但容易继续漂移。方案二是一次性重写边界层，模型完整但回归面过大。选定方案是“局部修复先行，共享原语收敛”：每个问题先用失败测试固定，再实现最小修复；同一批至少两个问题共享根因时，抽取小型请求身份、会话绑定或资源预算原语。

## 设计

- 权限请求提供稳定的内容指纹和 generation，评审、界面和响应绑定同一实例。
- 文件 provider 只接受非空、已登记、未关闭的 session context，不回退到历史根。
- secret 引用从配置身份、目标身份和字段路径派生，读取和删除都校验所有权。
- 权限展示与审计只保留安全摘要且不记录 secret。2026-07-21 的责任边界调整已取消客户端 egress 命令分类；外部副作用由 agent 与其工具负责。
- Markdown 渲染不允许自动网络或文件 I/O。
- transport、模型、渲染、任务和 artifact 在首次接收不可信数据时应用 byte、item、depth、pixel 和 lifetime 预算。
- session close 释放 replay、tool-call、terminal、stream 和 workspace-root 状态。

## 错误与兼容

安全关键值不静默截断；超限或身份不明时在 side effect 前明确失败。只有预览、历史和日志可以保存带 truncated 标记的安全摘要。有效 ACP/MCP 消息、已登记 session、用户批准的额外目录和正常大小附件保持可用。旧 agent 省略安全关键 session id 时返回协议错误。远端 Markdown 图片显示无 I/O 占位。

## 完成标准

每个改动遵循 RED、GREEN、REFACTOR。完成后运行格式、analyze、全量 Flutter 测试、native macOS 测试、release build、bundle/release scripts、依赖锁文件和同范围复审。只有 38 个保留项均被修复或被新证据证明不适用、所有命令通过、复审没有新问题时完成。
