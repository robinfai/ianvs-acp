# ChatGPT Desktop 参考图：组件拆分与复刻规格

## 视觉基准

- 基准图尺寸：`1990 × 1258 px`，浅色桌面窗口。
- 复刻目标：保留 ACP Client 的真实会话、工作区、上下文与终端能力，复用参考图的空间结构、表面层级、密度、圆角、投影和交互状态。
- 主视觉原则：大面积中性灰白；黑色承担主要操作；蓝色只用于焦点、未读与活动提示；边框低对比、投影轻且扩散。

## 布局约束

1. `≥1900px`：侧栏 360px；右侧检查器占位 362px；中间对话内容保持 848px 并在剩余区域居中。
2. `1280–1899px`：侧栏 320px；保留 362px 检查器列；对话区按约束收缩。
3. `<1280px`：检查器进入紧凑入口，不压缩主要对话任务。
4. `<780px`：侧栏进入底部弹层入口，保留标题、时间线与输入框的完整操作能力。
5. macOS 顶部不再额外占用一行原生标题栏：主工具栏从 `y 0` 开始，侧栏单独为原生窗口按钮预留空间；侧栏收起时，工具栏左侧预留 70px 避让窗口按钮。

## 字体与图标

- 字体栈：`.AppleSystemUIFont` → `SF Pro Text` → `PingFang SC` → `Helvetica Neue`。
- 正文：15px / 400；紧凑正文：14px / 400；小标签：12–13px / 500；标题：15.5–18px / 600。
- 代码：`SF Mono` → `Menlo`，13px / 1.5。
- 图标：使用 Flutter Material Icons 的圆角/线性变体，统一 17–19px；不使用字符图标、emoji 或手绘 SVG。

## 表面与动效

- 输入框：20px 圆角；外投影 `0 6 18 / 4.5%`，叠加 `0 1 4 / 2.5%`。
- 上下文浮层：20px 圆角；`0 8 24 / 8%`，叠加 `0 1 3 / 4%`。
- 普通悬停 120ms；面板、展开与状态切换 200ms；统一缓动 `cubic(0.2, 0, 0, 1)`。
- 焦点环使用蓝色 24% 透明度，不能以颜色作为唯一状态提示。

## 交互状态

- 侧栏：仅保留项目展开/折叠、会话选择、项目搜索、新建/恢复会话、代理设置与权限记录等项目已有入口。
- 工具栏：代理切换、恢复会话、终端开关、新建会话保持可用。
- 时间线：处理过程折叠、消息选择与链接点击保持可用。
- 输入框：多行输入、附件、权限策略、模型选择、发送/停止保持可用。
- 会话/上下文浮层：默认只显示当前会话、工作区和真实设置/能力入口；“查看全部”打开项目已有的 Workspace/Context 详情。
- 终端：默认延迟创建；用户打开后支持多标签、复制粘贴与快捷键切换。
